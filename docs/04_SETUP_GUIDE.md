# 04 — คู่มือเทคนิคสำหรับทีมโค้ด

## ภาพรวมสถาปัตยกรรม

ทุกระบบเป็น component บน GameObject `GameSystems` ในซีน ต่อสายกันผ่านช่อง Inspector
(สร้างและต่อสายอัตโนมัติแล้วโดยเมนู Tools > Heartbeat Overdrive > Setup Main Scene)

```
Conductor (นาฬิกา dspTime, คุม BPM ← Climax Shift อ่าน LineupFraction)
   │ OnBeat
   ▼
PulseSpawner (ปล่อยวงทุก N บีต) ──► PulseRing (หดเข้าวงเป้า)
   │ Active list
   ▼
InputJudge (Space/คลิก → Perfect/Great/Miss)
   │ OnJudged
   ▼
GameManager ──► HealthSystem (HP ผู้เล่น + ขบวนมอนสเตอร์)
   │                │ OnChanged / OnEnemyDefeated / OnBattleEnded
   ├─► FeedbackDirector (shake + hitstop + SFX)
   ├─► CharacterVisual (พุ่งตัว / กะพริบแดง / เฟดเข้า-ออกตอนสลับมอนสเตอร์)
   └─► HUDController (หลอดเลือด คอมโบ ป้ายตัดสิน ตัวนับมอนสเตอร์ หน้าผลพร้อมสถิติ)

RedlineEffect (อ่าน HP ผู้เล่นทุกเฟรม) ──► ขอบแดง + AudioDirector (หัวใจดัง/duck เพลง)
   └─ subscribe OnBattleEnded เอง เพื่อดับชีพจรตอนจบการดวล
```

หลักการสำคัญที่ห้ามเปลี่ยน:

1. **เวลาอ้างอิงเดียวของจังหวะคือ `Conductor.Now` (= AudioSettings.dspTime)**
   ห้ามใช้ Time.time ตัดสินจังหวะเด็ดขาด ไม่งั้นเพี้ยนตาม framerate/timeScale
   — และเวลา**ตั้งเวลาของบีต** ให้ใช้ `conductor.CurrentBeatTime` ไม่ใช่ `Now`
   เพราะ `OnBeat` ถูกยิงตอนต้นเฟรมถัดจากบีตจริง จึงช้ากว่าบีตได้ถึงหนึ่งเฟรม
   (16-33 ms ≈ ครึ่งหนึ่งของหน้าต่าง Perfect) ถ้าใช้ `Now` ทุกวงจะมี error สุ่มติดไปด้วย
2. **ค่าบาลานซ์อยู่ใน GameConfig ที่เดียว** — จูนใน Inspector ได้ระหว่างกด Play
   (ค่าจะเด้งกลับตอนออก Play mode — จดค่าที่ชอบไว้แล้วค่อยใส่กลับ)
3. ระบบคุยกันผ่าน event (OnBeat / OnJudged / OnChanged / OnEnemyDefeated / OnBattleEnded)
   จะเพิ่มฟีเจอร์ใหม่ให้ subscribe event ไม่ต้องไปแก้ไส้ระบบเดิม

## สถานะเกมและปุ่ม

`GameManager.State` วนอยู่สี่สถานะ: `Ready → Playing → Won / Lost → (Retry โหลดซีนใหม่)`

| ปุ่ม | ผล |
|---|---|
| Space / คลิกซ้าย | หน้า Ready = เริ่มดวล, ระหว่างดวล = ตีตามจังหวะ, หน้าผล = เล่นใหม่ |
| R | เล่นใหม่ (เฉพาะหน้าผล) |
| Esc | ออกจากเกม — ใน Editor จะหยุด Play mode ให้แทน |

หน้าผลแสดงสถิติจาก struct `BattleStats` (Perfect/Great/Miss, คอมโบสูงสุด, ความแม่น,
เวลา, จำนวนมอนสเตอร์ที่ล้ม) นับสะสมใน GameManager ระหว่างดวล เขียนลง `resultText`
ตัวเดิมด้วย rich text จึงไม่ต้องเพิ่ม Text ใหม่ในซีน

> หน้าผลกับปุ่ม Retry มี cooldown 0.8 วินาที กันกดรัวท้ายเกมแล้วเผลอเริ่มใหม่ทันที

## ตาราง GameConfig ที่จะได้จูนบ่อย

| ช่อง | ค่าเริ่มต้น | ผล |
|---|---|---|
| climaxMode | Tempo | Climax Shift เร่งอะไร: `Tempo` = เร่ง BPM, `Density` = ตรึง BPM แล้วปล่อยวงถี่ขึ้น (เลือก Density ถ้าจะใส่เพลงจริง) |
| baseBpm / maxBpmBonus | 90 / 60 | จังหวะเริ่ม / เร่งสูงสุดตอนขบวนศัตรูใกล้หมด (รวม 150) — ใช้เฉพาะโหมด Tempo |
| minBeatsPerPulse | 1 | โหมด Density: ความถี่สูงสุดตอนใกล้จบ (1 = ปล่อยวงทุกบีต) |
| enemies[] | 3 ตัว 40/55/75 HP | ขบวนมอนสเตอร์ (ดูหัวข้อถัดไป) — HP รวมคือความยาวหนึ่งแมตช์ |
| enemyFadeOutTime / InTime | 0.55 / 0.4 | เวลาเฟดตัวเก่าออก / ตัวใหม่เข้า |
| beatsPerPulse | 2 | ปล่อยวงทุก 2 บีต (ลดเหลือ 1 = โหดขึ้นมาก) |
| approachBeats | 3 | วงวิ่งนานกี่บีต (มากขึ้น = อ่านง่ายขึ้น) |
| perfectWindow / greatWindow | 0.065 / 0.13 | หน้าต่างตัดสิน (วินาที) |
| perfectDamage / greatDamage | 7 / 3 | ดาเมจใส่ศัตรู |
| enemyCounterDamage | 10 | โดนสวนตอน Miss |
| redlineStartFraction | 0.5 | HP ต่ำกว่านี้เริ่ม Redline |
| hitStopDuration / shakePerfect | 0.05 / 0.25 | น้ำหนักฟีดแบ็ก |

## ขบวนมอนสเตอร์ 3 ตัว

ตั้งค่าที่ `GameConfig > Enemies` บน GameSystems เป็น array — เพิ่ม/ลดจำนวนตัวได้อิสระ
(ใส่ตัวเดียวก็ได้ HUD จะซ่อนตัวนับให้เอง) แต่ละตัวมี `name`, `maxHp`, `sprite`, `bodyColor`, `scale`

ลำดับที่เกิดขึ้นตอนตีตัวหนึ่งตาย:

```
HealthSystem: EnemyHp ถึง 0 → OnEnemyDefeated(index)
GameManager.SwapEnemyRoutine():
  judge.Deactivate()           ← ปิดแค่การตัดสิน วง Pulse ยังไหลตามบีตต่อเนื่อง
  enemyVisual.FadeOutRoutine() ← ตัวเก่าจางหาย
  health.AdvanceToNextEnemy()  ← หลอดเลือดเติมเต็ม (ยิง OnChanged)
  ApplyEnemyLook()             ← สลับสไปรต์/สี/ขนาดเป็นตัวใหม่
  enemyVisual.FadeInRoutine()  ← ตัวใหม่ค่อยๆ ปรากฏ
  judge.Activate()             ← ทิ้งวงที่เลยเวลาไปเงียบๆ แล้วกลับมาตัดสินต่อ
```

> **ห้ามใส่ `spawner.End()` กลับเข้าไปในลูปนี้** เคยเป็นแบบนั้นแล้วพัง: พอหยุดปล่อยวง
> ผู้เล่นจะไม่มีตัวจับจังหวะทางสายตาเลยเกือบวินาที เหลือแต่เพลง แล้วยังต้องรออีก
> `approachBeats` บีตกว่าวงแรกจะวิ่งมาถึงเป้า รวมแล้วเงียบ 3 วินาทีกว่า —
> ผู้เล่นจะไปล็อกจังหวะกับเพลงแทน พอวงกลับมาก็รู้สึกทันทีว่าเพลงกับเกมไม่ตรงกัน
> ตอนนี้ `InputJudge.Activate()` ทิ้งวงที่เลยเวลาไปแล้วให้เองโดยไม่นับเป็น Miss

Conductor อ่าน `health.LineupFraction` (ความคืบหน้าของ**ทั้งขบวน**) ไม่ใช่ HP ตัวปัจจุบัน
BPM จึงไต่ขึ้นต่อเนื่องตลอดแมตช์ ไม่ตกกลับลงมาทุกครั้งที่มอนสเตอร์ตัวใหม่โผล่

## เพลง: หาจากไหน และทำยังไงให้ตรงจังหวะ

**ปัญหา:** BPM ของเกมขยับตลอดจาก Climax Shift (90 → 150) แต่ไฟล์เพลงมี BPM คงที่
ปล่อยไว้เฉยๆ เพลงกับเกมจะค่อยๆ หลุดจากกัน

**ตัวชี้จังหวะจริงของผู้เล่นคือวง Pulse + เสียงเคาะบีต ไม่ใช่เพลง** — สองอย่างนี้อิง
`AudioSettings.dspTime` จึงตรง 100% เสมอ เพลงเป็นเลเยอร์บรรยากาศ
(`AudioDirector.beatTickWithMusic` เปิดไว้ ให้เคาะเบาๆ ซ้อนบนเพลงเป็นไกด์)

### ขั้นตอนใส่เพลง

1. หาเพลงลูป **90 BPM** (= `baseBpm`) แนว electronic/synth ยาว 1-2 นาที
2. ตัดใน Audacity ให้ลูปยาว **ลงตัวเป็นจำนวนบีตพอดี** เช่น 32 บีต = 21.333 วินาที
   (ถ้าตัดไม่พอดี ทุกครั้งที่ลูปวนจะมีรอยสะดุดและเพลงจะเลื่อนออกจากบีตทันที)
3. import เข้า `Assets/Audio/` แล้วลากใส่ช่อง `Music Loop` ใน AudioDirector
4. ใส่ `Music Bpm` ให้ตรงกับ BPM จริงของไฟล์ (ค่าเริ่มต้น 90)

โค้ดเริ่มเพลงด้วย `musicSource.PlayScheduled(conductor.FirstBeatTime)` ไม่ใช่ `Play()`
เพลงจึงเริ่มตรงบีตแรกเป๊ะ (`Play()` เฉยๆ จะเริ่มต้นเฟรมถัดไป คลาดได้หลายสิบมิลลิวินาที)

### เลือกวิธีจัดการช่วง Climax Shift หนึ่งในสามทาง

| ทาง | ตั้งค่ายังไง | ได้/เสีย |
|---|---|---|
| **A. เพลงเป็นบรรยากาศ** (ค่าเริ่มต้น) | `syncMusicPitch = false` | ง่ายสุด ไม่มีเสียงเพี้ยน แต่ช่วงท้ายเพลงกับบีตจะไม่ตรงกัน |
| **B. เร่ง pitch ตาม BPM** | `syncMusicPitch = true`, `maxMusicPitch` 1.15 | เพลงล็อกกับบีตจริง แต่คีย์เพลงสูงขึ้นตาม ถ้าไม่ cap จะกลายเป็นเสียงการ์ตูน (150/90 = 1.67 เท่า สูงขึ้น ~9 เสียง) |
| **C. ตรึง BPM แล้วเร่งความถี่แทน** ← แนะนำถ้าจะใช้เพลงจริง | `climaxMode = Density` | เพลงตรงตลอดกาลไม่มีดริฟต์เลย ผู้เล่นยังรู้สึกว่าเกมเร่งขึ้นเพราะวงถี่ขึ้น |

ถ้าเลือก B ให้ลด `maxBpmBonus` เหลือราว 15-20 ด้วย จะได้ไม่ชน cap จนดริฟต์อยู่ดี

**ทำไม A ถึงหลุดจังหวะแน่นอน:** โหมด Tempo เร่ง BPM จาก 90 ไป 150 แต่ไฟล์เพลงเดินที่ 90
คงที่ สองอย่างนี้จึงถ่างออกจากกันเรื่อยๆ ตลอดแมตช์ ระหว่างเล่นปกติผู้เล่นตามวง Pulse
อยู่แล้วเลยไม่รู้สึก แต่พอมีจังหวะที่ต้องหยุดดูอย่างอื่น (เช่นตอนมอนสเตอร์ตาย) หูจะไป
เกาะเพลงแทน แล้วรู้สึกทันทีว่าไม่ตรง — **โหมด Density แก้ที่ต้นเหตุ** เพราะ BPM ไม่ขยับเลย

โหมด Density ปรับความถี่จาก `beatsPerPulse` ลงไปหา `minBeatsPerPulse` ตามความคืบหน้าของขบวน
(ค่าเริ่มต้น 2 → 1 สลับตอนเหลือครึ่งขบวน) ค่าลดลงอย่างเดียว กริดใหม่จึงเป็น superset
ของกริดเดิม วงที่ปล่อยออกมาไม่มีทางเลื่อนออกจากบีต

## วิธีแทน placeholder ด้วยของจริง

- **ผู้เล่น:** เลือก Player ในซีน → ลากสไปรต์ใส่ช่อง Sprite ของ SpriteRenderer
  (โค้ดจะสร้างวงกลมให้ *เฉพาะเมื่อช่องว่าง* เท่านั้น) สีตั้งที่ CharacterVisual.bodyColor
  — ถ้าใช้อาร์ตจริงให้ตั้งเป็นขาวเพื่อไม่ให้ tint ทับ
- **มอนสเตอร์:** ไม่ได้ใส่ที่ซีนแล้ว เพราะสลับตัวตอนรัน → ใส่ที่ `GameConfig > Enemies`
  ช่อง `sprite` ของแต่ละตัว (สีก็ตั้งเป็นขาวเหมือนกันถ้าใช้อาร์ตจริง)
- **วง Pulse:** ลากสไปรต์ใส่ช่อง `Ring Sprite` ของ PulseSpawner บน GameSystems
  (เว้นว่าง = ใช้วงแหวน placeholder ที่สร้างครั้งเดียวแล้วใช้ซ้ำทุกวง)
- **วงเป้า / ขอบแดง:** ลากสไปรต์ใส่ TimingTarget (SpriteRenderer) และ RedVignette (Image) ตรงๆ
- **เสียงทั้งหมด:** ลากไฟล์ใส่ช่องใน AudioDirector บน GameSystems
- **ฉากหลัง:** เพิ่ม GameObject ใหม่ + SpriteRenderer, ตั้ง sortingOrder = -10

## อยากเพิ่มอนิเมชันจริง

CharacterVisual มีเมธอด `Lunge()` กับ `FlashHurt()` เป็นจุดต่อเดียวที่ GameManager เรียก
→ เปลี่ยนไส้ในสองเมธอดนี้ให้ไปสั่ง `animator.SetTrigger(...)` แทนได้เลย ไม่ต้องแตะที่อื่น

## ข้อควรระวัง

- ซีนถูกสร้างจากสคริปต์ — ถ้าซีนพัง/สายหลุด ให้รัน Setup Main Scene ใหม่ได้เสมอ
  แต่การแก้ซีนด้วยมือหลังจากนั้น (เช่น ใส่อาร์ต) จะหายถ้ารัน Setup ซ้ำ → ระวัง + commit บ่อย
- ช่อง `Enemies` เพิ่งถูกเพิ่มหลังจากซีนถูกเซฟไปแล้ว **เปิด Unity ครั้งแรกให้เช็คว่ามีมอนสเตอร์
  ครบ 3 ตัวจริง** ถ้าขึ้นมาว่าง กรอกใน Inspector หรือรัน Setup Main Scene ใหม่
  (ถ้าปล่อยว่าง HealthSystem จะถอยไปใช้ศัตรูตัวเดียว 120 HP แบบเดิม ไม่พังแต่ได้เกมคนละแบบ)
- สไปรต์ placeholder ของวง Pulse ถูก cache ไว้ตัวเดียวใน `PlaceholderAssets.SharedPulseRing`
  อย่าเผลอเปลี่ยนกลับไปสร้างใหม่ทุกวง เพราะวงเกิดทุกบีต จะกระตุกตรงจังหวะและเท็กซ์เจอร์กองสะสม
- Retry ใช้การโหลดซีนใหม่ทั้งซีน ถ้าเพิ่มของที่ต้องรอดข้ามรอบ (เช่น เก็บสถิติ) ต้องใช้ static หรือ DontDestroyOnLoad
- ตอน build จริง: File > Build Profiles → ซีน Main ถูกใส่ใน Scene List ให้แล้วโดยสคริปต์ Setup
- โปรเจกต์ใช้ **Input Manager เดิม** (Input.GetKeyDown) — อย่าเผลอสลับ Active Input Handling
  เป็น Input System Package อย่างเดียว เดี๋ยวปุ่มเงียบทั้งเกม
