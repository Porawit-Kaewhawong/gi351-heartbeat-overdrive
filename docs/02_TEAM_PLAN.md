# 02 — แผนงาน 7 วัน (ทีม 4 คน: โค้ด 2 / อาร์ต 2)

## แบ่งบทบาท

| คน | บทบาท | รับผิดชอบ |
|---|---|---|
| **Code A** | Gameplay Core | Conductor, Pulse, InputJudge, HealthSystem, บาลานซ์ตัวเลข |
| **Code B** | Feel & UI | FeedbackDirector, RedlineEffect, AudioDirector, HUD, GameManager, ประกอบอาร์ตเข้าเกม |
| **Art A** | Character & Animation | ตัวละครผู้เล่น + ศัตรู, ท่าโจมตี/โดนตี, เอฟเฟกต์โดนตี |
| **Art B** | UI / BG / Audio | ฉากหลัง, วง Pulse + วงเป้า, HUD, หน้า Title/Result, หาหรือทำเพลงและ SFX |

> โค้ดระบบหลักทั้งหมดเขียนไว้ให้แล้ว (เล่นได้ end-to-end ด้วย placeholder)
> งานฝั่งโค้ดสัปดาห์นี้จึงเป็น **จูน / ขัด / ประกอบ / แก้บั๊ก** เป็นหลัก ไม่ใช่เขียนจากศูนย์

## แผนรายวัน

### วัน 1 — ตั้งหลัก
- ทุกคน: clone repo, เปิดด้วย Unity 6000.3.2f1, กด Tools > Setup Main Scene, เล่นให้ครบ 1 เกม
- Code A: อ่าน `04_SETUP_GUIDE.md`, ลองปรับค่าใน GameConfig ให้เข้าใจทุกช่อง
- Code B: ไล่โค้ด Feedback/HUD ให้เข้าใจจุดต่อ, ลิสต์สิ่งที่อยากขัดเพิ่ม
- Art A+B: อ่าน `03_ART_SPEC.md`, สเก็ตช์คอนเซปต์ตัวละคร+ฉาก, ตกลงสไตล์ร่วมกัน (แนะนำ: เส้นหนา สีจัด อ่านง่ายบนพื้นเข้ม)
- **จบวัน: ทุกคนรันเกมได้บนเครื่องตัวเอง + สไตล์อาร์ตถูกเลือกแล้ว**

### วัน 2 — แกนเกมนิ่ง
- Code A: เทสหน้าต่างตัดสินกับคนจริง 3-4 คน ปรับ perfect/great window, ปรับเส้นโค้ง Climax Shift
- Code B: ขัด Redline (จังหวะกะพริบ, ระดับเสียง), ขัด shake/hitstop ให้ "หนัก" กำลังดี
- Art A: สไปรต์ผู้เล่น (idle + hurt + attack), เริ่มศัตรู
- Art B: วง Pulse / วงเป้า / ฉากหลัง เวอร์ชันแรก
- **จบวัน: เกมด้วย placeholder "เล่นแล้วมัน" — นี่คือเช็คพอยต์สำคัญที่สุดของสัปดาห์**

### วัน 3 — อาร์ตลงเกมรอบแรก
- Code B + Art A: เอาสไปรต์ตัวละครเข้าแทน placeholder (ลากใส่ SpriteRenderer / ดูวิธีใน guide)
- Code A: เกลาบาลานซ์ HP/ดาเมจจากผลเทสวัน 2
- Art B: HUD จริง (หลอดเลือด กรอบ ฟอนต์), ภาพขอบแดง Redline แบบตั้งใจวาด
- **จบวัน: สกรีนช็อตเกมเริ่มเป็นเกมจริง ไม่ใช่วงกลม**

### วัน 4 — เสียง
- Art B: ส่งเพลงลูป (~90-100 BPM) + SFX ครบชุด (ดูสเปกในเอกสาร 03)
- Code B: ใส่เสียงจริงใน AudioDirector, ปรับระดับเสียงหัวใจ/duck เพลงตอน Redline
- Code A: เริ่มเก็บบั๊กจากการเทสภายใน
- Art A: เฟรมอนิเมชันเพิ่มเติม + เอฟเฟกต์ตอน Perfect (เช่น แฟลช/ประกาย)
- **จบวัน: เกมมีภาพและเสียงจริงครบลูป**

### วัน 5 — ความครบของเกม
- Code B: หน้า Title/Result เวอร์ชันสวย, ปุ่ม/ข้อความครบ, เช็ค Instant Retry ลื่น
- Code A: playtest กับคนนอกทีม 5+ คน จดตัวเลข (ชนะกี่ %, ตายที่ HP เท่าไหร่) แล้วปรับ
- Art A+B: เก็บงานภาพที่เหลือ, ภาพหน้าปก/โลโก้เกม
- **จบวัน: Feature freeze — หลังจากนี้ห้ามเพิ่มของใหม่ แก้บั๊กเท่านั้น**

### วัน 6 — ขัดเงา + กันพัง
- ทั้งทีม: playtest วนซ้ำ, แก้บั๊ก, ตัดของที่ไม่เสร็จออกอย่างใจแข็ง (ดูลำดับตัดในเอกสาร 01)
- Code B: ทำ build จริง (Windows) ตั้งแต่วันนี้ **ห้ามรอวันสุดท้าย** — บั๊กที่โผล่เฉพาะใน build มีเสมอ
- **จบวัน: build ที่เล่นได้จริงอยู่ในมือ**

### วัน 7 — ส่งงาน
- เช้า: build รอบสุดท้าย + เทสบนเครื่องที่ไม่ใช่เครื่อง dev อย่างน้อย 1 เครื่อง
- บ่าย: สกรีนช็อต, คลิปเกมเพลย์ 30-60 วิ, เขียนหน้าส่งงาน/สไลด์นำเสนอ
- กันเวลาเผื่อฉุกเฉินอย่างน้อยครึ่งวัน

## กติกาการทำงานร่วมกัน

- **ซีน Main.unity มีเจ้าของคนเดียวคือ Code B** — คนอื่นอยากแก้ซีนให้บอกก่อน
  (อาร์ตส่งไฟล์ภาพเข้า `Assets/Art/` ได้เลย ไม่ต้องแตะซีน แล้ว Code B เป็นคนประกอบ)
- ค่าบาลานซ์แก้ที่ **GameConfig ใน Inspector** ตัวเดียวเท่านั้น อย่า hardcode ในโค้ด
- commit บ่อยๆ พร้อมข้อความ, pull ก่อน push, มีปัญหา merge ให้ถามในกลุ่มทันที อย่าฝืน force
- ทุกเย็นใช้ 10 นาที: แต่ละคนพูดว่าวันนี้เสร็จอะไร พรุ่งนี้ทำอะไร ติดอะไร
