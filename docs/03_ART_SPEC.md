# 03 — สเปกงานอาร์ตและเสียง

แนวทางรวม: จอเกมพื้นโทนมืด (โค้ดตั้งพื้นหลังกล้องเป็นน้ำเงินเข้มเกือบดำ)
ของทุกชิ้นควร **อ่านง่ายบนพื้นเข้ม + สีตัดกันชัด** เพราะผู้เล่นต้องจับจังหวะด้วยตา

ไฟล์ทั้งหมด: **PNG พื้นหลังโปร่งใส** วางใน `Assets/Art/` (ภาพ) และ `Assets/Audio/` (เสียง)
ตอน import ตั้ง Texture Type = Sprite (2D and UI)

## ภาพ — ลำดับความสำคัญสูง (ต้องมี)

| # | ชิ้นงาน | ขนาดแนะนำ | หมายเหตุ |
|---|---|---|---|
| 1 | ตัวละครผู้เล่น: idle | ~512x512 | หันขวา ยืนฝั่งซ้ายจอ |
| 2 | ตัวละครผู้เล่น: attack | ~512x512 | 1-2 เฟรมพอ (โค้ดพุ่งตัวให้แล้ว) |
| 3 | ตัวละครผู้เล่น: hurt | ~512x512 | โค้ดกะพริบแดงให้แล้ว มีท่าเฉพาะยิ่งดี |
| 4 | ศัตรู: idle / attack / hurt | ~512x512 | ใหญ่กว่าผู้เล่นเล็กน้อย ดูมีพลังกดดัน |
| 5 | วง Pulse | 512x512 | วงแหวนเส้นชัด ตรงกลางโปร่งใสสนิท |
| 6 | วงเป้า (Timing Zone) | 512x512 | ต่างจากวง Pulse ชัดเจน เช่น เส้นประ/เรืองแสง |
| 7 | ฉากหลังสนามดวล | 1920x1080 | โทนมืด อย่าให้ลายตรงกลางแย่งสายตาจากวงเป้า |
| 8 | ภาพขอบจอแดง (Redline) | 1024x1024 | กลางโปร่งใส ขอบแดงเข้ม ไล่เกรเดียนต์นุ่ม |

## ภาพ — ลำดับรอง (มีแล้วเกมดูโปร)

| # | ชิ้นงาน | หมายเหตุ |
|---|---|---|
| 9 | โลโก้เกม + หน้า Title | ใช้ตอนเปิดเกมและหน้าปกส่งงาน |
| 10 | กรอบหลอดเลือด HUD | ให้เข้าธีม "ชีพจร/คลื่นหัวใจ" เช่น ปลายหลอดเป็นเส้น EKG |
| 11 | เอฟเฟกต์ Perfect | ประกาย/แฟลชตอนกดเป๊ะ 2-4 เฟรม |
| 12 | หน้า Win / Lose | ภาพประกอบผลแพ้ชนะ |

## เสียง (Art B ดูแล — หาไฟล์ฟรี license ถูกต้อง หรือทำเองก็ได้)

| ชิ้น | สเปก | หมายเหตุ |
|---|---|---|
| เพลงประกอบลูป | 90-100 BPM, ลูปไร้รอยต่อ, 1-2 นาที | แนว electronic/synth เร้าใจ อย่าใส่เสียงเพอร์คัสชันถี่เกินจนตีกับเสียงเคาะบีตของเกม |
| SFX Perfect | สั้น <0.3s โทนสว่าง สะใจ | สำคัญสุดในเกม ลงทุนกับชิ้นนี้ |
| SFX Great | เบา/เรียบกว่า Perfect ชัดเจน | |
| SFX Miss | โทนทึบ/ต่ำ รู้สึก "พลาดแล้ว" | |
| เสียงหัวใจเต้น "ตุบ" 1 ครั้ง | สั้น เบสหนัก | โค้ดเป็นคนคุมความถี่/ความดังเอง ส่งมาแค่ตุบเดียว |
| SFX ชนะ / แพ้ | 1-2 วินาที | |

วิธีส่งมอบ: วางไฟล์ลง `Assets/Audio/` แล้วแจ้ง Code B — การแทนที่เสียง placeholder
ทำโดยลากไฟล์ใส่ช่องใน AudioDirector (Inspector) ใช้เวลาไม่ถึงนาทีต่อไฟล์

## เช็คลิสต์คุณภาพก่อนส่งทุกชิ้น

- ดูรู้เรื่องเมื่อย่อเหลือ ~25% ของขนาดจริง (ขนาดที่เห็นจริงในเกม)
- ทดสอบวางบนพื้นสีเข้ม ไม่ใช่พื้นขาวของโปรแกรมวาด
- ตัวละครสองตัวใช้จานสีคนละโทนชัดเจน (แนะนำ ผู้เล่น = ฟ้า/เขียว, ศัตรู = แดง/ม่วง
  ให้ตรงกับสีหลอดเลือดใน HUD)
